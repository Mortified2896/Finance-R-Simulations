# Manual Tools

Double-clickable launchers and browser helpers are grouped by workflow:

- `analysis/`: schema setup, validation, title/subtitle scoring checks, and terminal rating.
- `images/`: thumbnail scoring checks and Medium image download utilities.
- `import/`: manual stats importers, bookmarklets, and import notes.
- `rating/`: local browser-based human rating apps.
- `watchers/`: Medium tag/page watcher launchers and snippets.
- `reference/`: small reference notes used by manual tools.
