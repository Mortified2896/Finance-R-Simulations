Medium Own Stats Page Saver

This tool runs only on the Medium stats page you already have open in your normal browser. It does not use automation. It saves the current /me/stats page HTML to a local file so the separate own-stats importer can parse the dashboard table later. It does not directly import anything into SQLite.

Install

  1. Open this HTML file in your browser.
  2. Drag this bookmarklet link to your bookmarks bar:

Save Medium Stats Page

  1. Open https://medium.com/me/stats normally in your browser.
  2. Wait until the stats table is visible.
  3. Click the Save Medium Stats Page bookmarklet.
  4. Save the downloaded file anywhere convenient, or into debug_samples/Stats Page/.
  5. Run 01_manual_tools/import/start_medium_own_stats_importer.command.
  6. Drag/drop or paste the saved HTML file path into Terminal, then press Enter.
  7. The importer will add own articles to medium_articles and private snapshots to medium_own_story_stats.

What This Does

The bookmarklet only saves the current Medium stats page HTML. The actual database import happens later in Terminal through 01_manual_tools/import/start_medium_own_stats_importer.command, which then runs scripts/import_medium_own_stats_from_html.R.
