Medium Tag Page Bookmarklet Helper

This bookmarklet runs on a Medium tag page you already opened in your normal browser. It does not use automation. It extracts the currently visible tag-page article cards and downloads a JSON file.

Install

  1. Open this HTML file in your browser.
  2. Drag this bookmarklet link to your bookmarks bar:

Medium Tag Page JSON

  1. Open a Medium tag page such as https://medium.com/tag/finance or https://medium.com/tag/finance/recommended.
  2. Scroll until enough article cards are visible.
  3. Click the Medium Tag Page JSON bookmarklet.
  4. Import the downloaded JSON file with 01_manual_tools/start_medium_own_stats_importer.command.
