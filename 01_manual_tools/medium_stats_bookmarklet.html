Medium Stats Bookmarklet Helper

This bookmarklet runs only on the page you have already opened in your normal browser. It does not make network requests, does not use automation, and does not save full HTML. It copies only visible article text and public metadata from the current page.

Install

  1. Open this HTML file in your browser.
  2. Drag this bookmarklet link to your bookmarks bar:

Medium Stats JSON

  1. Open a Medium article normally in your browser.
  2. Click the Medium Stats JSON bookmarklet.
  3. Review or edit claps, responses, and follower counts in the review modal.
  4. Press OK so the bookmarklet copies one JSON object to your clipboard.
  5. Return to Terminal and import the current clipboard.
